# AdvanceJava

A collection of Advanced Java programs and practice exercises, organized chapter by chapter.

## About

This repository holds my work while learning Advanced Java. Each chapter folder contains the example programs and exercises for that topic, so the code can be read and run in the order it was learned.

## Repository Structure

```
AdvanceJava/
├── CHAPTER 1/    # Chapter 1 programs and exercises
├── CHAPTER 2/    # Chapter 2 programs and exercises
├── CHAPTER 3/    # Chapter 3 programs and exercises
├── CHAPTER ../   # Chapter .. programs and exercises
├── .idea/        # IntelliJ IDEA project settings
└── README.md
```

## Prerequisites

- **JDK 8 or later** (JDK 17 or newer recommended)
- An IDE such as **IntelliJ IDEA** (the project includes IntelliJ settings), Eclipse, or VS Code with the Java extension
- Git, to clone the repository

Check your Java installation:

```bash
java -version
javac -version
```

## Getting Started

Clone the repository:

```bash
git clone https://github.com/rajan21045/AdvanceJava.git
cd AdvanceJava
```

Then open the folder in IntelliJ IDEA (**File → Open**) and let it index the project.

## Running the Programs

**From the IDE:** open a `.java` file that contains a `main` method and click the green Run icon.

**From the command line:**

```bash
cd "CHAPTER 1"
javac YourProgram.java
java YourProgram
```

Replace `YourProgram` with the class name. If the file declares a `package`, compile and run from the project's source root using the fully qualified class name.
